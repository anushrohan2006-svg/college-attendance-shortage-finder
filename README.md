# College Attendance Shortage Finder

## Project Purpose
This web application helps students and teachers track attendance, identify shortages, and calculate how many future classes a student must attend to reach the required percentage.

## Features
- Add student attendance records
- Save records in a CSV file
- View attendance dashboard
- View subject-wise charts
- Find a student’s attendance
- Identify attendance shortages
- Calculate classes needed to reach 75% attendance
- Preview a CSV attendance file
- Download an attendance report

## Technology Used
- Python
- Streamlit
- Pandas
- CSV file storage

## Run the Project
Open the project folder in VS Code and run:

py -m streamlit run app.py
